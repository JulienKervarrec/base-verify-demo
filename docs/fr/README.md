# Parcours francais : base-verify-demo (verification de comptes sociaux et anti-Sybil)

Lecture pedagogique du depot base/base-verify-demo : une application Next.js demontrant Base Verify, un service de verification de comptes sociaux avec jetons deterministes anti-Sybil, dans une implementation hors-chaine et une implementation on-chain.

Sommaire :

Chapitre 1 Presentation de base-verify-demo. Chapitre 2 Encoder provider, traits et action dans un message SIWE. Chapitre 3 Validation des traits cote serveur et flux hors-chaine. Chapitre 4 La variante on-chain, jeton EIP-712 et deduplication par smart contract. Chapitre 5 Limites et perimetre de ce parcours.

Ce parcours est une lecture pedagogique du code source et de la documentation du depot, sans installation ni execution du projet.
